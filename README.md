# Portal-BOT v2.0: Autonomous AI Player for Portal 1

Локальная программа-бот для полностью автономного прохождения игры **Portal 1** на ПК с использованием гибридной системы: **Computer Vision (60+ FPS)**, **Source Engine Console Log Bridge** (100% достоверные события игры), **Closed-Loop Actuation** (PID-наведение) и **Hierarchical HTN Planning с прогрессивными fallback-стратегиями**.

---

## 🌟 Что нового в версии 2.0

1. 📡 **Source Engine Log Bridge & State Fusion**:
   - Автоматическое чтение и парсинг консольных логов игры (`con_logfile "portal_bot_log.txt"`, `developer 1`).
   - 100% точное распознавание состояния игры:
     - Уровень портальной пушки (**No Gun** в Камерах 00–01, **Single Blue Gun** в Камерах 02–10, **Dual Portal Gun** в Камерах 11–19).
     - Достоверное открытие/закрытие дверей и нажатие/отжатие напольных кнопок без ложных срабатываний.
     - Точное отслеживание установленных синих и оранжевых порталов.
2. ⚡ **Производительность 60+ FPS**:
   - Оптимизированный векторизованный конвейер компьютерного зрения.
   - Тест производительности подтверждает **78+ FPS** на обычном ПК без подвисаний и задержек.
3. 🔁 **Прогрессивные Fallback-стратегии (Multi-Stage Action Strategies)**:
   - Если бот не может взять куб с первой попытки:
     - **Этап 1**: Прямое наведение по центру и нажатие `E`.
     - **Этап 2**: Подход вплотную, наклон камеры вниз на пол + приседание (`Ctrl`) + `E`.
     - **Этап 3**: Шаг назад, боковой стрейф для изменения угла, повторное центрирование и подход.
     - **Этап 4**: Прыжок с подбором в воздухе (для кубов на постаментах и уступах).
   - Аналогичные многоэтапные стратегии для доставки куба на кнопку и прохода в двери.
4. 🧭 **Умная навигация без бесконечных вращений (Anti-Spin Navigation)**:
   - Замена бесконечного кружения на дискретное 4-секторное сканирование (90°).
   - После сканирования текущей точки бот **физически перемещается вперед** в центр камеры, меняя ракурс.
5. 💻 **Обновленный веб-интерфейс Aperture Science**:
   - Отображение статуса соединения с логами игры (**GAME LOG: LIVE / DISCONNECTED**).
   - Индикатор инвентаря пушки (**NO GUN / SINGLE (BLUE) / DUAL PORTAL GUN**).
   - Кнопка **[ ⚙️ SYNC LOGS ]** для автоматической установки `portal_bot.cfg` в игру в 1 клик.
   - Счетчик FPS реального времени и отображение текущей стратегии агента.

## 📦 Быстрый старт

### 1. Установка
```bash
pip install -r requirements.txt
pip install -e .
```

### 2. Настройка игры Portal 1 (один раз)
В консоли игры Portal 1 (`~`) введите:
```cfg
con_logfile "portal_bot_log.txt"; developer 1
```
*(Или нажмите кнопку **[ ⚙️ SYNC LOGS ]** в веб-панели управления бота для авто-настройки).*

### 3. Запуск бота
```bash
python run_bot.py
```
Откройте в браузере: **`http://localhost:8000`** и нажмите **`[ ▶ START BOT ]`**.

### 4. Экстренная остановка
В любой момент нажмите клавишу **`F8`** на клавиатуре или кнопку **[ EMERGENCY STOP ]** в веб-интерфейсе. Все клавиши моментально отпустятся, вернув управление человеку.

### 5. Запуск тестов
```bash
pytest -v
```
*(Все 29 unit- и benchmark-тестов проходят успешно).*
